# M8.7 所有用户管理视图排除系统管理员

> 状态：✅ 已完成
> 创建：2026-08-13
> 前置：M8.5（系统管理员视图下拉）、M8.6（用户管理视图收紧）

## 一、需求原文

> 系统管理员登录后，在用户管理的所有用户管理中，不应该显示系统管理员的数据。
> 只显示所有普通管理员和所有普通操作员数据。

## 二、需求解读（设计决策）

| 角色               | 系统用户管理（sys 视图）     | 所有用户管理（all 视图）                                         |
| :----------------- | :--------------------------- | :--------------------------------------------------------------- |
| 系统管理员（平台） | 平台系统管理员（不变，M8.5） | **排除系统管理员**，仅显示：普通管理员（租户管理员）+ 普通操作员 |

关键决策：

1. **后端 `GET /users/all` 过滤系统管理员**：`listAllUsers()` 由 `findAll()` 改为 `findAll().stream().filter(u -> !u.isSystemAdmin())`——只返回租户归属用户（tenant_id 非空），系统管理员（role=admin 且无租户）天然被排除
2. **前端不变**：所有用户管理视图本就是只读列表（无按钮操作），后端返回即显示
3. **系统用户管理（sys）视图不变**：仍显示平台系统管理员（M8.5 需求，可创建/重置密码）
