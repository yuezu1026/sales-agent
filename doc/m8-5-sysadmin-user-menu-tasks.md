# M8.5 任务清单：用户管理页下拉切换（系统用户管理 / 所有用户管理只读）

> 状态：✅ 已完成
> 需求来源：用户「在系统管理员登录后，用户管理，能否分为系统用户管理和所有用户的管理，所有用户只显示列表信息，不做操作，是否可以做成下拉点击菜单。而普通管理员登录后，他的用户管理，只管理他自己租户的用户，且可以对他管理的普通用户做改密，禁用等管理」

---

## 〇、需求原文

1. 系统管理员登录后 → 用户管理页分为两个视图（下拉点击菜单切换）：
   - **系统用户管理**：现有功能（只显示系统管理员、创建系统管理员、重置密码）
   - **所有用户管理**：显示所有租户所有用户，**只读列表，无任何操作按钮**
2. 普通管理员（租户管理员）登录后 → 用户管理只管理本租户用户，可对其管理的普通用户做**改密、禁用**等管理（M8.4 已实现 ✅）

## 一、设计决策

- 后端新增 `GET /api/users/all`（仅系统管理员可调，`requireSystemAdmin`）：返回所有租户所有用户（含租户名），**无写操作**
- 前端 `Users.tsx`：平台视角（`isSystemAdmin()`）顶部显示下拉菜单「系统用户管理 / 所有用户管理」；「所有用户」视图为只读表格（含租户名列，无操作列）；租户管理员视角不变（现状已满足）
- 下拉实现：原生 `<select>`（可靠、无定位问题），放页面标题下方

## 二、改动清单

- [x] `backend/.../service/UserService.java`：加 `listAllUsers()`（`findAll()` + 租户名批量映射，复用 `UserVO`）；抽取 `toUserVOs()` 公共方法
- [x] `backend/.../controller/UserController.java`：加 `GET /users/all`（`requireSystemAdmin`，仅系统管理员可调）
- [x] `frontend/src/pages/Users.tsx`：平台视角（`isSystemAdmin()`）标题下方下拉「系统用户管理 / 所有用户管理」；「所有用户」只读表格（含「所属租户」列、无「操作」列、无按钮）；切到该视图时懒加载 `/users/all`；租户管理员视角不变
