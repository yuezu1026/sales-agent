# M7.2 任务清单：登录页增加「重置」按钮（清空重输）

> 状态：✅ 已完成（2026-08-09）
> 需求来源：用户「登录页面，怎么没有重置按钮？……我的意思，有没有一个重新输入，可能用户输入错误密码。」

---

## 一、需求原文

1. 登录页目前只有「登 录」按钮，没有重置/清空按钮。
2. 用户输入错误密码（或用户名输错）时，希望能一键清空重新输入，避免手动逐字删除。
3. 非"忘记密码"功能（后端无 email 字段，重置密码由 admin 在用户管理页完成，已与用户确认过方向）。

---

## 二、设计决策

| 项   | 决策                                                                                               |
| :--- | :------------------------------------------------------------------------------------------------- |
| 方案 | 登录框登录按钮旁新增「重 置」按钮：点击清空用户名 + 密码 + 错误提示 msg                            |
| 布局 | 两个按钮等宽并排（flex，gap 12px），按钮样式统一 .btn，重置用 .btn-default（白底灰边，区分主操作） |
| 交互 | 重置后不触发任何请求；清空错误提示；输入框留空聚焦不处理（保持简单）                               |
| 后端 | 零改动（纯前端）                                                                                   |

---
