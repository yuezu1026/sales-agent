# M8.4 任务清单：系统管理员用户管理边界收紧（平台只管系统管理员）

> 状态：✅ 已完成
> 需求来源：用户「系统管理员应该不具备创建普通操作员的管理权限，而系统管理员登录进去的用户管理中，显示的应该都是系统管理员，普通操作员只让租户的普通管理员去管理，请帮我看看这个逻辑是否OK？」→ 确认决策点「admin 密码只能由他自己修改，但是他可以修改或者重置其他系统管理员的密码」→ 追加「admin 演示默认账号禁止修改，包括他自己」

---

## 〇、需求原文

1. 系统管理员不能创建普通操作员（已有，`createUser` 已限制）✅
2. 系统管理员用户管理列表**只显示系统管理员**（现状：显示所有租户所有用户 ❌）
3. 普通操作员只由租户管理员管理（现状：系统管理员可重置任意租户用户密码/启停 ❌）
4. **admin 密码只能自己修改**（个人设置），但可**重置其他系统管理员的密码**
5. **追加（演示版保护）**：admin 是默认公开账号，**暂时禁止修改，包括他自己** —— 任何人（含 admin 本人）都不能重置/修改 admin 密码；admin 在个人设置页隐藏修改密码表单，在用户管理页无任何操作按钮

## 一、设计决策（权限矩阵）

| 操作      | 系统管理员（平台）对系统管理员                                                    | 系统管理员对租户用户               | 租户管理员对本租户用户                  |
| :-------- | :-------------------------------------------------------------------------------- | :--------------------------------- | :-------------------------------------- |
| 查看列表  | ✅ 仅平台系统管理员                                                               | ❌ 看不到                          | ✅ 本租户                               |
| 创建      | ✅ 仅平台账号                                                                     | ❌ 403                             | ✅ operator/admin                       |
| 重置密码  | ✅ 可重置他人；**不能重置自己**（自己走个人设置）；**admin 受保护任何人不可重置** | ❌ 403「租户用户由租户管理员管理」 | ✅ 不能重置系统管理员；**不能重置自己** |
| 启用/禁用 | ❌ 系统管理员账号不可禁用                                                         | ❌ 403「租户用户由租户管理员管理」 | ✅ 不能禁用自己                         |
