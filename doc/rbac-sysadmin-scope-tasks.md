# 系统管理员权限收窄任务（仅用户管理，不触达租户数据）

## 状态

- 状态：✅ 已完成（2026-08-12 启动，同日完成）
- 前置：RBAC 三级角色改造已完成（`doc/rbac-tasks.md` ✅）
- 目标：系统管理员（平台级，tenant_id NULL）登录后**只能查看注册用户**，租户业务数据（客户/邮件/潜客/画像/模板/系统设置）不能察看、更不能替租户用户操作

## 需求原文（用户 2026-08-12）

> 系统管理员，只能查看注册用户，租户的数据不能察看。更不能替用户操作

### 追加需求（用户 2026-08-12，工作台统计）

> 系统管理员可以在工作台察看所有用户登录统计，和访问者地理分布。而普通管理员或者租户管理员，只能查看自己租户或者组织或者公司的用户登录统计和他组织下的访问者地理分布

- 工作台（Dashboard）对所有角色开放：系统管理员看**全平台**登录统计+地理分布；租户管理员/普通用户看**本租户**统计
- 后端三个统计接口按当前登录用户租户过滤（登录日志需记录租户归属）

### 追加需求 2（用户 2026-08-12，角色创建权限）

> 超级管理员，他只能创建超级管理员，不能创建普通管理员和普通用户。普通管理员可以创建自己租户下的其他普通管理员和普通用户。

- 权限矩阵：超级管理员 → 只能创建超级管理员（平台级）；租户管理员 → 创建本租户普通管理员 + 普通用户；普通用户 → 不能创建
- 连带：租户管理员可管理（重置密码/启停）本租户普通管理员与普通用户（否则创建的管理员无人可管）

## 现状分析

| 层面         | 现状                                                                                                                               | 缺口            |
| :----------- | :--------------------------------------------------------------------------------------------------------------------------------- | :-------------- |
| 后端数据隔离 | 业务接口 Repository/Service 均用 `TenantContext.require()`，系统管理员 tenantId=null → 400「当前账号无租户上下文」已挡住数据与操作 | ✅ 已满足       |
| 前端菜单     | Nav 只按 `isAdmin`（role=admin）判断，系统管理员会看到 工作台/客户管理/邮件 等全部业务菜单                                         | ❌ 需隐藏       |
| 前端登录跳转 | Login 登录成功一律 `navigate("/")`（工作台），系统管理员进入工作台会触发多个 400                                                   | ❌ 需按角色跳转 |
| 前端路由     | 无路由守卫，系统管理员可手动输入 /customers 等 URL 进入业务页（同样触发 400）                                                      | ❌ 需加守卫     |

## 设计决策

| 决策点                   | 结论                                                                                                                |
| :----------------------- | :------------------------------------------------------------------------------------------------------------------ |
| 系统管理员可见页面       | 仅「用户管理」+「帮助」；工作台/客户管理/潜客挖掘/客户画像/收件箱/草稿箱/发件箱/邮件模板/系统设置/个人设置 全部隐藏 |
| 系统设置是否给系统管理员 | 不给。系统设置页读的是租户级 SystemConfig（`TenantContext.require()`），系统管理员无租户，打开即 400                |
| 路由守卫位置             | `App.tsx` 统一包一层 BizGuard：系统管理员访问业务路由 → `<Navigate to="/users">`；登录/注册/退订/用户管理/帮助 放行 |
| 登录跳转                 | 系统管理员 → `/users`；其他角色 → `/`（工作台）                                                                     |
| 后端                     | 不改。`TenantContext.require()` 已阻止系统管理员读/写租户数据（400，属业务校验不用 401）                            |
